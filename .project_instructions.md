# LegacyLegion Platform

## Overview
LegacyLegion is the lead-generation operating system built for LegacyAI.space (Indianapolis AI-first marketing firm). It powers multi-channel intake, AI scoring, kanban pipeline, CRM-lite, partner portal, and analytics — behind a dark, professional UI.

## Visual Style
- Dark mode forced via `<html className="dark">` in `app/layout.tsx`
- Accent: violet/fuchsia gradient (CSS var `--primary: 263 78% 60%`)
- Typography: DM Sans body, Plus Jakarta Sans display, JetBrains Mono code
- Layouts: `Container`, `Section`, `PageHeader` from `components/layouts`

## Architecture
- Auth: NextAuth credentials (email/password)
- LLM: ABACUSAI_API_KEY → /v1/chat/completions (model `gpt-5.4-mini`)
- Pinecone: multilingual-e5-large embeddings via `https://api.pinecone.io/embed`
- Agent: streaming bridge `/api/agent/stub` (LLM-backed)

## Routes
- `/` Landing
- `/login` `/signup` Team auth
- `/get-started` Public lead-capture form with streaming AI assessment
- `/partner/login` `/partner/signup` Partner auth
- `/partner/portal` Partner dashboard + `/refer` submission form
- `/app` Team app (dashboard, leads, pipeline, analytics, ROI, intelligence, agent settings, import, referrals)

## Schema notes
- `Lead` requires: `businessName`, `ownerName`, `email`, `industry`. Pipeline: `status` field. Owner: `assignedToId`.
- `ReferralPartner` requires `name`, `email`, `category`, `partnerCode`.
- `ReferralSubmission` requires `businessName`, `contactName`, `contactEmail`.
